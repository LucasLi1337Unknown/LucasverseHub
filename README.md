## ✨ Features

- Project cards grouped by category
- Search and category filters
- 🎲 **Send Me Somewhere Random**
- ⚙️ **In-site settings panel**
- Dark/light mode
- Open-in-new-tab preference
- Animation toggle
- Compact card mode
- Local settings saved in the browser
- Public / in-development project badges
- Mobile-friendly layout
